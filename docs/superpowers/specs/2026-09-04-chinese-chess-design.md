# Chinese Chess（小朋友象棋）設計定案

日期：2026-09-04
狀態：已與需求方逐項確認（三輪訪談），本文件是實作依據。

## 1. 目標

給 7 歲小朋友玩的中國象棋網頁。打開網址就能玩，不用安裝、不用登入。
頁面標題 **Chinese Chess**，介面文字繁體中文。
網址：`https://max8568.github.io/chinese-chess/`

## 2. 技術

- Vite + TypeScript，不用 UI 框架。
- 棋盤與棋子用 SVG 畫在 DOM 上；拖曳用 Pointer Events（滑鼠、觸控通用）。
- 規則引擎與電腦對手是純函式模組，用 Vitest 自動測試；介面用瀏覽器手動測。
- 電腦搜尋跑在 Web Worker，避免第 3 級思考時卡住畫面。
- 支援近兩年的 Chrome、Edge、Safari（含 iPad）。不支援 IE。
- 不使用 localStorage、cookie 或任何持久化；重新整理就回到預設。

### 2.1 程式模組

```
src/
  engine/     規則：棋盤狀態、走法產生、合法性、將軍、終局
  ai/         評估函式、Alpha-Beta 搜尋、難度設定、Worker 入口
  ui/         棋盤繪製、拖曳與點選、設定列、被吃棋子條、對話框、橫幅
  audio/      Web Audio 合成音效、音檔覆寫、靜音
  assets/     素材座標表（棋盤交叉點、棋子圖檔對照）
  main.ts     組裝
tools/
  prepare-assets.py   把 assets/ 原圖處理成網頁用檔（見 §8）
```

### 2.2 座標約定

- `file` 0–8：由左到右（以紅方在下方為準）。
- `rank` 0–9：由上到下；rank 0 是黑方底線，rank 9 是紅方底線。
- 棋盤狀態是 90 格的陣列，每格為空或 `{ side, type }`。
- `side`：`red` | `black`。`type`：`general` `advisor` `elephant` `knight` `rook` `cannon` `soldier`（沿用素材 manifest 的命名）。
- 玩家選黑棋時只翻轉「畫面」，內部座標不變。

## 3. 規則

實作：
- 所有標準走法：蹩馬腿、塞象眼、象不過河、仕（士）與帥（將）不出九宮、炮隔一子吃、兵（卒）過河前只能前進、過河後可橫走。
- 將帥不能照面（同一路中間無子時不可）。
- 走出讓自己被將的棋視為不合法（送將不可）。
- 紅方先行。
- 終局：被將死或困斃（無合法走法）即輸。困斃訊息：「X 方沒有棋可走，Y 方獲勝」。

不做：長將長捉判負、六十回合和棋、和棋協議、認輸、棋鐘、每步時限。
無和棋。若雙方無限循環，遊戲不會自行結束。

## 4. 電腦對手

- Minimax + Alpha-Beta，走法排序吃子優先。
- 評估：子力分數（rook 900、cannon 450、knight 400、elephant 200、advisor 200、soldier 100、過河 soldier 200、general 10000）加簡單位置分（兵過河、馬車靠中）。
- 三級難度，預設 1：
  - **1**：深度 1。有子可吃就在能吃的走法中隨機挑一步；否則在所有合法走法中隨機挑。不躲、不看對手下一步。
  - **2**：深度 2。會躲要被吃的子、會抓沒保護的子。
  - **3**：深度 4，加吃子延伸（quiescence，只算吃子，最多再 4 層）。
- 同分走法隨機挑一步，避免每局一樣。
- 避免立刻重複：若最佳走法會回到最近 4 個半步內出現過的局面，且有分數差在 50 以內的其他走法，改走其他走法。
- 每步至少停 0.6 秒再落子（搜尋較快時補足等待），期間顯示「電腦思考中…」。
- 電腦思考中玩家不能動棋，悔棋與提示按鈕變灰。
- 玩家選黑棋時，棋盤翻轉、玩家在下，電腦（紅）自動先走。
- 難度切換立即生效，不重開局。

## 5. 介面

### 5.1 版面

- 沒有選單頁。打開就是一局雙人對戰。
- 橫向（桌機、平板橫放）：棋盤在左，設定列在右。
- 直向（平板直放、手機）：棋盤在上佔滿寬度，設定列在下。
- 棋盤依可用空間縮放，維持圖片比例。
- 按鈕最小高度 48px。
- 被吃棋子條貼著棋盤上下各一條（§5.5）。

### 5.2 設定列（由上到下）

1. 狀態：「輪到紅方」/「輪到黑方」大字加紅色或黑色色塊；電腦思考時改為「電腦思考中…」。
2. 模式：雙人 / 電腦。預設雙人。
3. 顏色：紅 / 黑。只在電腦模式顯示。預設紅。
4. 難度：1 / 2 / 3。只在電腦模式顯示。預設 1。
5. 悔棋。
6. 提示。只在電腦模式顯示。
7. 重新開始。
8. 音效開 / 關（喇叭圖示）。

切換模式或顏色時：已有走過棋就先問「要重新開始嗎？」（大大的「是」「否」兩顆按鈕的自製對話框，不用 `window.confirm`）；還沒走過就直接換並重開。
重新開始：已有走過棋就問，沒走過直接重開。

### 5.3 走棋操作

- 兩種都能走：拖曳到目的地放開；或點一下棋子、再點一下目的地。
- 只能拿起輪到的一方的棋子。
- 拿起（點選或開始拖曳）時顯示可走位置：空點畫圓點，可吃的子外圍畫圈；被拿起的棋子有亮框。
- 拖曳放到不合法位置或放開在棋盤外：棋子彈回原位（0.15 秒動畫），不顯示原因。
- 點選模式點到不合法位置：取消選取；若點到自己另一顆棋則改選那顆。
- 點選走法與電腦走子：棋子從起點滑到終點 0.2 秒。拖曳放下直接落定。被吃的子 0.2 秒淡出。
- 上一步標記（2026-09-04 追加，原本不做）：最後走的那一步，起點與終點各畫一個淡綠色外圈，
  大小與選取外框相同。走完就更新，悔棋時退回上一步的位置，開新局清除。
  加這個是因為電腦走完之後看不出來哪一顆動了。
- 被拿起的棋子外框是白色；不顯示座標、不做圖案棋子。

### 5.4 將軍與終局

- 被將軍的一方的帥／將閃爍約 1 秒，播放將軍音效。
- 將死或困斃：棋盤上蓋一條橫幅「紅方獲勝！」或「黑方獲勝！」（困斃時副標「X 方沒有棋可走」），兩顆按鈕：「再來一局」、「悔棋」。棋盤維持可見。
- 「悔棋」會關掉橫幅並退回被將死前，可以繼續玩。

### 5.5 被吃棋子條

- 棋盤下方那條放「下方那一方吃到的子」；上方那條放「上方那一方吃到的子」（戰利品放自己面前）。棋盤翻轉時跟著換邊。
- 同種合併顯示：小棋子圖加「×N」。
- 固定順序：rook、knight、cannon、elephant、advisor、soldier；沒有的不顯示。
- 悔棋時對應的數量減一，減到 0 就消失。

### 5.6 悔棋

- 雙人模式退一個半步；電腦模式退兩個半步（電腦那步加玩家那步）。若電腦模式下只剩一個半步（玩家選黑、電腦先走那步），悔棋按鈕變灰。
- 次數不限。遊戲結束後仍可悔棋。
- 電腦思考中不可悔棋。

### 5.7 提示

- 只在電腦模式、輪到玩家、且不在思考中時可按。
- 永遠用第 3 級搜尋找一步，把該棋子與目的地亮起約 2 秒（與可走位置相同的圓點與亮框樣式），小朋友自己走。
- 次數不限。

## 6. 音效

- 四種事件：落子、吃子、將軍、勝利。以 Web Audio 程式合成，不依賴檔案。
- 若 `assets/web/sounds/{drop,capture,check,win}.mp3` 存在（頁面載入時以 fetch 檢查），改用音檔。
- 靜音按鈕，狀態只存在記憶體，重新整理回到有聲。
- 第一次使用者互動時才建立 AudioContext（瀏覽器限制）。

## 7. 不做的事（明確排除）

長將長捉、和棋、認輸、棋鐘、選單頁、存檔、記住設定、座標、圖案棋子、雙人模式的提示、被吃棋子逐顆顯示。

## 8. 素材

採用 `assets/` 內的點陣素材（AI 生成後以 `extract-assets.ps1` 從 `xiangqi-assets-sheet.png` 切出）。

量測事實（棋盤圖 2026-09-04 下午更新後重新量測）：
- `assets/board/board-empty.png` 2048×2304。格線等距 220，左上角交叉點在 (144, 162)，
  所以直線 x = 144 + 220i（i = 0..8），橫線 y = 162 + 220j（j = 0..9）。
  以實際像素驗證，誤差在 1 像素以內。
- `assets/board/grid-overlay.png` 1024×1152，正好是上圖的一半，格線位置一致；程式不使用它。
- 14 張棋子圖 512×512，圓盤直徑約 450，但圓心位置各不相同（x 250–278）。

（更新前的舊圖是 2048×1952 且格線不等距，最右一路寬約三成；`src/assets/boardGeometry.ts`
換成等距公式後不再需要逐點座標表。）

處理方式（`tools/prepare-assets.py`，輸出到 `assets/web/`，Vite 的 `publicDir` 指向這裡）：
- 棋盤：等比縮到 1536 寬，存成有透明度的 WebP（品質 85）。
- 棋子：以 alpha ≥ 250 的範圍裁切、置中到正方形畫布、縮到 384×384 PNG。
- `src/assets/boardGeometry.ts` 記錄棋盤圖尺寸、格距與左上角交叉點（以原圖像素為單位，程式按縮放比例換算）；棋子放在交叉點上，直徑取格距的 0.92 倍。之後換棋盤圖只需改這五個數字；若新圖格線不等距，把 `files` 與 `ranks` 換成逐點座標陣列即可，其他程式不會受影響。

`assets/README.md` 與 `assets/manifest.json` 保留作為素材說明。

## 10. 測試

- `engine/`：每種棋子的走法、蹩馬腿、塞象眼、過河規則、九宮限制、炮的隔子吃、將帥照面、送將不合法、將軍偵測、將死與困斃判定、悔棋還原（含被吃子）。
- `ai/`：第 1 級有子可吃必吃；第 2 級會躲單步被吃；第 3 級能找到一步將死；避免重複規則生效；搜尋結果永遠是合法走法。
- 介面：桌機 Chrome 與 iPad Safari 手動走完一局雙人、一局對電腦（含選黑）、悔棋到開局、切換模式的確認框、靜音。
